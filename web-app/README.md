# say.mine — 웹 실행본

설문과 경험을 입력하면 개인화된 OPIc 말하기 연습 카드를 만듭니다.
개인 사이드 프로젝트의 개발 기준은 이 웹 앱입니다. 이전 Colab 실습 노트북은 보관용이며 웹 서버에서 사용하거나 자동 동기화하지 않습니다.

## 준비

Python 3.12, Node.js 22.13 이상, [Ollama](https://ollama.com/download)가 필요합니다.
API 키는 필요 없으며 최초 모델 다운로드에 인터넷과 약 2.5GB의 저장 공간이 필요합니다.

Ollama 앱을 먼저 켜거나 별도 터미널에서 `ollama serve`를 실행하세요.
이후 프로젝트 폴더에서 실행합니다.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
npm ci
ollama pull qwen3:4b-instruct
```

Windows에서는 `py -3.12 -m venv .venv`로 만들고,
활성화 대신 `.\.venv\Scripts\python.exe`를 사용할 수 있습니다.

## 실행

Python 가상환경의 터미널:

```sh
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

별도 터미널:

```sh
npm run dev -- --hostname 127.0.0.1
```

브라우저에서 http://127.0.0.1:5173/ 를 엽니다. 기본값으로 실행할 때 .env는 필요 없습니다.

## 주요 파일

- app/page.tsx: 설문·경험 입력과 결과 화면
- app/api/: Python 백엔드로 요청 전달
- backend/main.py: 생성 API 서버
- backend/core.py: 입력 검증 → 프롬프트 → LLM → 결과 파싱
- backend/knowledge.md: 프롬프트에 넣는 학습 기준
- components/study-tools.tsx: 표현 비교·말하기 연습·정보 추가·정정
- components/study-library.tsx: 기록 목록·주제 검색·즐겨찾기·복습 화면
- lib/library.ts: 기록 정렬·필터·즐겨찾기·개별 삭제
- lib/session.ts: JSON 검증·저장·복원 및 TXT 내보내기
- lib/local-workspace.ts: 작성 중인 입력과 노트의 브라우저 저장 형식·검증
- hooks/use-local-workspace.ts: 자동 저장·충돌·실패 처리

실제 모델은 Ollama에서 실행합니다. 유효한 경험 입력이 25자 미만이면 LLM 호출 없이 미리 작성한 보완 질문을 반환합니다. 사용자가 경험을 추가해 다시 생성합니다.
표현 수준마다 문장 결합·어휘·수식 방식의 규칙을 다르게 적용합니다. 경험·묘사는 유형별 3단계 예시를 넣어 영어 초안 세 개를 한 번에 생성합니다. 롤플레이는 `RunnableBranch`로 분기하여 같은 확정 사실에 수준별 규칙·예시 하나씩을 넣고 세 번 순차 호출합니다. 직접 질문→연결 질문→간접 질문의 구분을 유도하며 앞서 생성한 초안은 다음 수준의 사실로 전달하지 않습니다. 예시는 별도 상황이며 사용자 경험으로 복사하지 않도록 구분합니다. 선택한 초안으로 연습 카드를 한 번 더 생성합니다.
유효한 긴 입력은 경험·묘사 2회, 롤플레이 4회가 기본입니다. 선택한 초안에서 원문에 없는 숫자값·부호·영어 요일명이 발견되거나 보조 카드의 형식·언어 검증에 실패하면, 각 단계에서 한 번만 수정 요청합니다. 경험·묘사는 최대 4회, 롤플레이는 최대 6회이며 재검증 실패는 오류로 반환합니다. 숫자·요일 검사는 아라비아 숫자값과 명시된 한국어/영어 전체 요일명만 비교합니다. 요일 약어·날짜 계산·누락·부정·감정·인과관계 등 의미 전체는 검증하지 못합니다. 질문에 나온 요일은 확정 사실로 사용하지 않습니다.
이 제한된 검사를 통과한 영어 초안은 카드 단계에서 변경하지 않습니다. 한국어 연습 팁은 수준별로 미리 작성한 안내이며 나머지 카드 내용은 LLM이 생성합니다.
한국어 뼈대는 3–6개 항목으로 만들며 원문과 추가 답변의 마지막 행동·감정까지 포함하도록 요청합니다. 항목 제한을 완화해도 의미 누락이 완전히 방지되는 것은 아닙니다.
브라우저 자동 저장은 기본 꺼짐입니다. 켜면 설문·경험 입력과 생성된 노트·이전 기록을 저장하고 다음 방문에 복원합니다. 파일 백업은 사용자가 직접 실행합니다. 공식 채점이나 등급 보장 기능은 아니며 결과의 사실 확인이 필요합니다.
인증 없는 로컬 학습용이므로 서버를 인터넷에 공개하지 마세요.

## 개발 검증

```sh
python -m unittest backend.test_core
npm test
npx tsc --noEmit
npm run build
```

로컬 모델을 실제로 호출하는 품질 회귀 예제는 별도로 실행합니다.

```sh
python -m backend.evaluate
```

정보 추가·30분→20분 정정·카페 묘사·카페 롤플레이·도서관 묘사·호텔 롤플레이·시끄러운 카페·휴관한 박물관의 여덟 입력을 순서대로 실행합니다. 마지막 네 입력은 프롬프트 예시와 다른 내용이며 부정·불확실성·요일도 확인합니다. `--output /원하는/새파일.json`으로 입력과 결과를 저장할 수 있으며 기존 파일은 덮어쓰지 않습니다. 예제별 핵심 표현·한국어 뼈대·일부 원문에 없는 표현을 확인하는 제한된 패턴 검사입니다. 통과가 의미·문법 검증 완료를 뜻하지 않고, 정상적인 바꿔 말하기를 누락으로 볼 수도 있습니다. 이 전체 회귀 검사는 웹 요청 시 실행하지 않습니다.

로컬 Qwen 비교에서 롤플레이의 질문 구조는 분리 생성으로 더 구분됐지만, 경험·묘사의 사실 누락은 일관되게 개선되지 않아 이 두 유형은 기존 방식을 유지합니다. 도서관 입력의 자격증 공부·저녁 시간 누락 및 원문에 없는 집중 이유 추가는 남은 한계입니다. 예제별 검사 결과와 원문을 함께 확인해야 합니다.

원문 체크리스트 추가, 초안 재검토, 문장별 번역 후 생성도 비교했지만 누락 감소와 함께 새 이유·잘못된 수량이 생겨 채택하지 않았습니다. 호출 횟수는 유지하며 명시적 숫자·요일 오류는 제한적으로 차단하고, 원문 대조 화면으로 사용자의 확인을 돕습니다.

## 비교하고 직접 말하기

- 결과의 ‘원문과 세 가지 표현 비교’에서 원문·추가 답변과 수준별 영어 초안을 나란히 비교합니다. 원문은 실제 생성에 사용한 입력을 문장·줄 단위로 나눈 것으로, LLM 요약이나 자동 판정 결과가 아닙니다. 질문 안의 가정은 원문 목록에 넣지 않습니다. 숫자·요일 검사를 통과한 초안만 표시하며, 선택한 수준을 수정한 경우 수정본을 표시합니다. 비교해도 원래 노트의 표현·키워드는 바뀌지 않습니다.
- ‘말하기 연습 시작’에서 전체 답변 → 한국어 뼈대 → 영어 키워드 → 질문만 순서로 연습합니다. 타이머와 단계별 완료 표시는 연습 화면을 떠나면 초기화됩니다. 녹음·음성 인식은 사용하지 않습니다.
- 결과 아래의 보완 질문에 답하면 원문과 추가 답변으로 노트를 다시 생성합니다. 실패하면 기존 노트와 작성한 답변을 유지합니다. 질문은 사실이 아닌 문맥으로 전달하며 원문과 답변의 합계는 1,500자, 추가 답변은 최대 12개입니다. 원문을 수정하면 이전 추가 답변은 초기화됩니다.
- 시간·동행자 등 잘못된 사실은 ‘기존 내용 정정’에서 올바른 전체 이야기를 확인한 뒤 재생성합니다. 이전 원문·추가 답변은 새 컨텍스트에서 제외하며 성공 후에만 이전 기록으로 보관합니다. 정정에 실패하면 기존 노트와 작성 중인 내용을 유지합니다.
- 표현 점검은 수준 간 높은 유사도, 일부 분사 표현, 강도 표현을 알려주는 규칙 기반 안내입니다. 자동 교정·채점이 아니며 오탐과 누락이 있습니다. 추가 답변을 확정 사실로 명시해도 모델이 누락하거나 의미를 바꿀 수 있습니다.
- ‘읽기용 TXT’는 입력·비교 답변·검토 안내·이전 이야기 요약을 저장합니다. ‘이어하기용 JSON’은 현재 노트와 이전 노트 최대 10개를 저장합니다. 불러오기는 2MB 이내 버전 1 파일을 검사하고, 교체 확인 후에만 현재 화면에 반영합니다.
- JSON 파일은 브라우저에서 읽습니다. 자동 저장이 켜져 있으면 불러온 기록도 브라우저 저장 대상으로 바뀝니다. 다시 생성을 누를 때 현재 설문·확정 사실만 로컬 모델에 전달합니다. 정정 전 이야기도 JSON에 남으므로 파일 공유 전에 확인하세요.
- 자동 저장이 꺼졌거나 실패한 경우 미저장 입력·노트에 대해 이탈 경고를 요청합니다. 작성 중인 보완 답변·정정문과 말하기 타이머는 자동 저장·파일 백업 대상이 아닙니다. 보완 답변·정정문에 변경이 있으면 이탈 경고를 유지합니다.

## 브라우저에서 이어하기

- 상단의 ‘이 브라우저에 자동 저장 켜기’를 눌러 동의한 뒤 사용합니다. 입력 변경 400ms 후 저장하며 ‘저장됨’ 표시를 확인하세요. 새로 열 때 검증한 기록으로 마지막 입력 단계 또는 노트를 복원하며 LLM을 다시 호출하지 않습니다.
- `localStorage`의 `say.mine.workspace.v1` 키 하나에 현재 설문·경험, 현재 노트, 이전 노트 최대 10개를 저장합니다. 보완 질문의 확정 답변은 노트 입력에 포함되지만 아직 제출하지 않은 작성창은 제외합니다. 자동 저장용 서버·DB·클라우드 전송은 없습니다.
- 같은 브라우저·프로필·출처(프로토콜/호스트/포트)에서만 이어집니다. `localhost:5174`와 `127.0.0.1:5174`는 서로 다른 저장 공간입니다. 브라우저 데이터 삭제·시크릿 모드 종료로 기록이 사라질 수 있으므로 JSON 백업을 병행하세요. 암호화 저장이 아니므로 공용 기기에서는 사용하지 마세요.
- Web Locks로 읽기·쓰기를 직렬화하고 기존 레코드가 바뀌었는지 확인합니다. 다른 탭이 변경하면 자동 저장을 중단하고 현재 화면은 유지합니다. 기록을 덮어쓰지 않으며 다른 탭을 확인한 뒤 새로고침해 최신 기록을 불러옵니다. Web Locks나 저장소 접근이 지원되지 않으면 자동 저장을 비활성화하고 파일 백업을 안내합니다.
- 저장 용량 부족·손상된 형식·지원하지 않는 버전은 기존 기록을 자동 삭제하거나 덮어쓰지 않습니다. 현재 작성 내용도 유지됩니다. 다른 탭 충돌은 새로고침 전 현재 노트를 JSON으로 백업하고, 아직 생성하지 않은 경험은 따로 복사해 두세요.
- ‘자동 저장 끄고 기록 지우기’는 별도 확인 후 해당 키만 삭제합니다. 현재 화면·다운로드한 파일·다른 사이트 기록은 지우지 않습니다. 삭제 후에는 다시 켜기 전까지 기록을 재생성하지 않습니다.

## 학습 기록 보관함

- ‘학습 기록 보관함’은 현재 노트와 이전 기록을 생성일 최신순으로 보여줍니다. 주제 필터, 원문·확정 추가 답변·영어 답변 검색, 즐겨찾기 필터를 함께 사용할 수 있습니다. 동일한 날짜의 기록도 각각 관리합니다.
- ‘이 기록으로 복습’은 저장된 노트로 대본 가리기·키워드 말하기·원문 비교를 제공합니다. 생성 API를 호출하지 않고 현재 작업의 설문·경험·작성 중인 보완 답변을 바꾸지 않습니다. 모델이 꺼져 있어도 저장된 답변을 복습할 수 있습니다. 짧은 입력으로 받은 규칙 기반 보완 질문은 영어 답변이 아니므로 별도로 표시합니다.
- 보관함을 열면 현재 말하기 타이머는 종료됩니다. 복습 타이머도 목록이나 현재 작업으로 돌아가면 초기화됩니다. 타이머·완료 표시·검색 조건은 영구 기록이 아닙니다.
- 현재 노트 + 이전 최대 10개를 보관합니다. 새 생성 전에 보관 가능 여부를 검사하며, 한도 초과 시 즐겨찾기가 아닌 오래된 이전 기록부터 정리합니다. 11개 모두 즐겨찾기면 생성 전에 중단하고 즐겨찾기 해제·개별 삭제를 안내합니다. 즐겨찾기는 이 기록 버전에만 적용되며 새 생성본에 자동으로 복사하지 않습니다.
